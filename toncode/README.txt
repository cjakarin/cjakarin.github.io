ต้นโค้ด — HTML สำหรับ GitHub Pages
=================================
บทเรียน C / C++ / Python 3 ภาษาไทย 7 บท ตั้งแต่เริ่มต้นถึงฟังก์ชัน
มี 78 โจทย์: พื้นฐานเดิม 60 ข้อ และโจทย์ฟังก์ชัน 18 ข้อ
ทุกข้อมีแบบเติมโค้ดและแบบเขียนโปรแกรมเต็มบน eLabSheet ทั้ง 3 ภาษา

ลำดับบทเรียน
------------
1. โครงสร้างโปรแกรมและการแสดงผล
2. ตัวแปร ชนิดข้อมูล และการรับข้อมูล
3. นิพจน์และตัวดำเนินการ
4. if / else และตรรกะ
5. for และตัวนับ/ตัวสะสม
6. while ค่าหยุด และลูปซ้อน
7. ฟังก์ชัน: การประกาศ พารามิเตอร์ การเรียก return และขอบเขตตัวแปร
ทุกบทมีคำอธิบายโครงสร้างก่อนตัวอย่าง และโจทย์ฝึกท้ายบท

เปิดใช้งาน
----------
เปิด index.html ได้โดยตรง หรือให้บริการโฟลเดอร์นี้ผ่านเว็บเซิร์ฟเวอร์
ไม่ต้องติดตั้งแพ็กเกจหรือ build ไม่มีระบบหลังบ้าน
ใช้ HTML, CSS และ JavaScript ปกติ และใช้ Google Fonts เมื่อต่ออินเทอร์เน็ต

ขึ้น GitHub Pages
----------------
1. สร้างหรือใช้ repository ที่ต้องการ
2. แตก ZIP และอัปโหลดไฟล์ข้างในไปยังรากของ repository
   ให้ index.html อยู่ระดับบนสุด ไม่อัปโหลด ZIP โดยไม่แตกไฟล์
3. ไปที่ Settings > Pages
4. Source: Deploy from a branch, Branch: main, Folder: / (root), กด Save
5. เมื่อเผยแพร่เสร็จ กด Visit site
อ้างอิง: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
ใช้พาธสัมพัทธ์และมี .nojekyll จึงรองรับทั้ง user site และ project site

โครงสร้างไฟล์
-------------
index.html          โครงหน้าเว็บ
style.css           รูปแบบและหน้าจอมือถือ
app.js              บทเรียน โจทย์ ตัวกรอง และตัวจำลองลูป
practice-links.js   ลิงก์ผู้เรียนแบบเขียนเต็มและแบบเติมโค้ด
fill-code.js        แม่แบบเติมโค้ดและคำอธิบายช่องว่างสำหรับผู้เรียน
.nojekyll           ให้บริการไฟล์โดยตรงบน GitHub Pages

วิธีฝึก
-------
เปิดโจทย์แล้วเลือก เติมโค้ดในช่องว่าง หรือ เขียนโปรแกรมเต็ม
แบบเติมโค้ด: อ่านแม่แบบแล้วเลือกภาษาเพื่อเปิดโจทย์บน eLabSheet
เติมเฉพาะช่องว่างใน eLabSheet ตามลำดับโครงสร้างที่มีให้
แบบเขียนเต็ม: เขียนโปรแกรมฉบับเต็มในช่องโค้ด แล้วกด ส่งคำตอบ
ผลการตรวจอยู่บน eLabSheet ไม่ได้ส่งกลับมายังเว็บนี้
แบบเขียนเต็มตรวจผลลัพธ์; ข้อกำหนดด้านรูปแบบ/การใช้ฟังก์ชันให้ผู้สอนพิจารณาประกอบ
แบบเติมโค้ดมีโครงสร้างกำหนดไว้แล้วและตรวจผลลัพธ์หลังแทนค่าช่องว่าง

การแก้ไข
--------
แก้ lessons, syntaxGuides และ tasks ใน app.js
แก้ TONCODE_PRACTICE ใน practice-links.js สำหรับแบบเต็ม
แก้ TONCODE_FILL_PRACTICE สำหรับแบบเติมโค้ด
cpp หมายถึง C++, c หมายถึง C, py หมายถึง Python 3
eLabSheet เลือก c++11 ตามตัวเลือกที่ระบบมีให้ ตัวอย่างทั้งหมดรองรับ C++11
ความคืบหน้าการอ่านเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น
ตัวจำลองลูปเป็นสื่ออธิบายคำสั่งที่กำหนดไว้ ไม่ใช่คอมไพเลอร์

สำหรับผู้สอน
-------------
ลิงก์แก้ไข ต้นฉบับ และคำตอบของช่องเติมอยู่ใน ZIP ผู้สอนที่ส่งแยก
เก็บไฟล์ผู้สอนเป็นส่วนตัว ไม่อัปโหลดรวมกับเว็บสาธารณะ
คู่มือ eLabSheet: https://elabsheet.org/tutorial.pdf
แบบฝึกหัดเป็นแนวพื้นฐานทั่วไป ไม่ได้อ้างว่าเป็นโจทย์ใหม่ทั่วโลก
เว็บไซต์นี้ไม่ใช่เว็บไซต์ทางการของ TOI0
